# 本地工作台的 Cron 目录隔离

公共配置中的 Cron 启用状态等参数继续由各工作目录继承，但 `cron.dataDir` 仅供声明该配置的工作目录使用，不传播到其他工作目录。

其他工作目录默认使用自身目录作为 Cron 数据根目录，任务保存在其 `.cron/` 下，无需逐个创建配置文件。目录自己的配置可以显式指定 `cron.dataDir`；其中相对路径仍以配置文件所在目录解析。

原目录的 Cron 数据及已有任务保持原位，不迁移或复制到其他项目。普通会话的创建不再因 Cron 初始化失败而中断；服务终端会报告警告，实际调用 Cron 工具时仍会返回对应错误。显式配置同一数据目录的多个项目仍被禁止共享调度器，以免定时任务在错误项目执行。

修改后需重启 Web 服务。新会话使用新路径解析规则，已有会话仍保持其参数快照；若旧会话保存了冲突路径，请新建会话。
