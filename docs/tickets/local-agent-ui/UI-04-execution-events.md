# UI-04 — 实时文本与工具执行时间线

类型：AFK · 状态：未开始 · 依赖：[UI-02](UI-02-workspaces.md)  
父级：[Spec](../../specs/2026-09-18-local-agent-ui.md) · 故事：US06

## 要交付什么

从 Agent 引擎发出结构化事件，经持久化和 Web 订阅进入页面，实时显示文本、工具开始/结果/失败和重试状态。时间线简洁，点击可查看参数与输出，长内容折叠。终端适配器消费同一事件，不将 console 文本作为协议。

## 验收条件

- [ ] 任务结束前已能显示真实文本增量和工具执行状态，不能只在最终回复时刷新。
- [ ] 事件具有 Spec 定义的归属 ID 和单 Run 序号，并在任务执行期间持续保存。
- [ ] 多个并行工具调用按 toolCallId 正确关联输入和结果，失败尝试文本不会混成最终成功回复。
- [ ] 订阅可从游标补发，快照与订阅切换无遗漏；重复事件不导致重复渲染。
- [ ] 工具参数和输出脱敏后保存/显示，HTML 被安全呈现为内容，长输出可展开。
- [ ] 模型错误和工具错误具有明确状态及保留的部分结果，不伪造完成或内部思维链。
- [ ] 持久化失败有明确错误与停止准入行为，不继续确认无法记录的新任务。

## 验证与演示

可控模型发出文本分块、并行工具事件、一次重试和错误，检查 UI 顺序、关联和持久化回放；模拟重复事件及订阅竞争窗口。整体页面恢复在 UI-08 收口。
