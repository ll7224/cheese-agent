# UI-02 — 多目录接入与会话归属

类型：AFK · 状态：已实现，集成回归见 UI-10 · 依赖：[UI-01](UI-01-bootstrap-chat.md)
父级：[Spec](../../specs/2026-09-18-local-agent-ui.md) · 故事：US02、US03

## 要交付什么

用户在页面输入已有本机文件夹绝对路径，添加或选择工作目录，再创建会话并执行任务。目录与会话关系持久化，列表按目录切换，当前目录始终可见。工具与子 Agent 接收显式工作目录；会话不能原地换目录。

核对文件工具、shell、技能、记忆、RAG、使用记录及预览工具的路径来源，避免启动目录污染任务目录；这一工作属于本功能的执行上下文接入，不扩展成文件浏览器。

## 验收条件

- [ ] 已有可访问目录可接入，规范化后的同一真实目录去重；文件、相对路径和不存在路径有明确错误。
- [ ] 两个目录中的同名相对文件分别返回正确内容；shell 执行目录与所选目录一致。
- [ ] 切换目录只改变当前浏览上下文，不改变已有 Session 的 workspaceId。
- [ ] 文件、消息、工具注册中的可变会话状态不串到另一个目录；不通过 process.chdir 或修改全局环境切换目录。
- [ ] 接入记录重启后可读；目录移除或失去访问权限时保留历史入口并禁止新执行。
- [ ] 两个同目录会话可创建，共享真实文件，无自动 worktree 或目录复制。

## 验证与演示

使用两个临时目录放置内容不同的同名文件，分别执行读写和 shell pwd；验证符号链接路径去重、失效路径与会话归属。真实并发验证由 UI-05 承接。

## 实施记录

目录使用真实绝对路径去重，页面显示可用性；失效目录保留历史，拒绝新会话和执行。每个任务的子进程由 fork 的 cwd 参数绑定目录，主服务不切换 cwd，现有文件/shell/技能/记忆路径自然在任务进程内解析。目录覆盖配置在 UI-03 完成。新增别名去重、路径读取、失效目录和历史保留测试。
