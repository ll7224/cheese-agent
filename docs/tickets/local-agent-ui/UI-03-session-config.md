# UI-03 — 目录配置与会话配置版本

类型：AFK · 状态：未开始 · 依赖：[UI-02](UI-02-workspaces.md)  
父级：[Spec](../../specs/2026-09-18-local-agent-ui.md) · 故事：US04

## 要交付什么

创建会话时合并服务公共配置与目录覆盖，记录有效配置版本。页面展示实际模型、目录与配置错误；旧会话继续使用旧版本，新会话采用新配置。无需配置编辑 UI。

实施 Spec 6.2 的合并、路径来源、凭据引用和全局额度规则。将配置读取从“出错即退出全进程”改为可由当前会话呈现错误的调用契约。

## 验收条件

- [ ] 部分目录覆盖保留公共配置未覆盖字段，false 生效、数组整体替换、默认值在合并后填充。
- [ ] 公共及目录配置中的相对路径分别相对其声明文件解析，不随活动会话变化。
- [ ] 修改配置后，旧会话显示并使用保存的参数版本，新会话采用新版本；服务重启后仍成立。
- [ ] 原始密钥不出现在 API、UI、普通配置快照或执行事件中；凭据引用缺失时明确报错。
- [ ] 一个目录配置错误不会终止服务或影响其他会话，不因错误静默换成 Mock 模型。
- [ ] 目录配置无法扩大服务主任务或子 Agent 全局额度；现有配置及旧名称回退保持兼容。

## 验证与演示

使用可辨认的两个模型替身及配置版本演示旧/新会话行为、错误隔离和重启读取。验证合并边界及脱敏响应，不将“冻结技能文件内容”作为配置版本能力。
