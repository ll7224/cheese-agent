# UI-09 — 科幻首页与完整工作区体验

类型：HITL（视觉验收） · 状态：已实现并完成代理浏览器检查，用户视觉偏好待审阅 · 依赖：[UI-08](UI-08-recovery.md)
父级：[Spec](../../specs/2026-09-18-local-agent-ui.md) · 故事：US05、US13、US14、US15

## 要交付什么

将已有功能打磨成完整首页和 Agent 工作区。首页以深色粒子核心为视觉主体，同时提供目录选择、直接输入任务和最近会话；提交后自然进入三栏工作区，动效收敛为小型状态标识。

用真实任务状态驱动反馈，所有关键行为可直接操作。基于可运行页面提供截图或演示供人眼确认视觉方向，不要求用户先批准尚不存在的实现。

## 验收条件

- [ ] 首页具备目录添加/选择、任务输入、最近会话，首屏可见主要操作，不强制观看开场动画。
- [ ] 粒子核心具备轻微空间纵深，输入与任务状态反馈一致，进入工作区后不持续占据正文区域。
- [ ] 左侧列表可收起，右侧详情按需展开；目录、模型、连接、运行/排队状态清晰可见。
- [ ] 空目录列表、无历史、目录不可用、配置错误、运行失败和断线状态都有可操作的真实反馈。
- [ ] 同目录其他运行会话提示与停止操作可见；执行期间输入草稿保留但不能提交。
- [ ] 刷新保留当前会话且不重播入场动效，返回首页有明确入口。
- [ ] 减少动态效果模式、键盘导航、焦点恢复、长输出折叠和窄屏抽屉均可用。
- [ ] 后台标签页暂停装饰动画；默认与减少动态效果两种模式均完成人眼验收。

## 验证与演示

用已实现服务完成首页提交、切会话、查看工具、停止和恢复全过程。检查桌面/窄屏与两种动态偏好；提交视觉产物及所发现的问题，不以静态设计图替代功能验收。

## 实施记录

完成深绿暗色首页、Canvas 粒子核心、真实运行概览、目录弹窗、三栏工作区、历史执行详情、会话草稿、幂等提交和静态视觉切换。遵循系统减少动态效果并在后台/工作区暂停粒子。Codex 浏览器实测首页发起/回复、停止、刷新保留草稿、新目录会话、静态模式和 390×844 布局；浏览器无 error 日志。已修复切换会话后的 SSE 连接与发送按钮布局。用户尚未做人眼偏好确认，不把代理视觉检查写成用户批准；后续技术验收继续进行。
