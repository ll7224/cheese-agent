# UI-06 — 子 Agent 全局调度与可视化

类型：AFK · 状态：未开始 · 依赖：[UI-05](UI-05-concurrent-runs.md)  
父级：[Spec](../../specs/2026-09-18-local-agent-ui.md) · 故事：US07、US09

## 要交付什么

多个主任务派生的子 Agent 共用独立的全局默认 3 个运行额度。超额子任务排队并显示状态，运行后回填摘要。每个子任务关联 rootRunId 和 parentRunId，继承父会话目录与配置；保留深度限制。

## 验收条件

- [ ] 两个以上主任务同时派生时，子 Agent 总运行数不超过配置额度，不按会话乘倍扩张。
- [ ] 超额派生可见地排队，不像原批量切片逻辑一样静默遗漏，也不把额度等待当成执行失败。
- [ ] 主任务与子任务使用独立额度池，父任务等待子任务时不会占满子任务额度导致调度死锁。
- [ ] 页面可展开正确的父子关系、状态、摘要与错误；子 Agent 操作使用父任务的目录和配置。
- [ ] 完成、失败与超时都正确释放额度；超时计时从实际执行开始，排队时间单独记录。
- [ ] 排队、运行与终态事件持久化，超时和错误可区分，深度限制仍有效。

## 验证与演示

多个主任务总计派生超过三项，以可控阻塞验证全局峰值、FIFO 推进、父子归属及超时回收。取消链由 UI-07 完成。
