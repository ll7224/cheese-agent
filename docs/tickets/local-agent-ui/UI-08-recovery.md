# UI-08 — 会话恢复与服务重启收敛

类型：AFK · 状态：未开始 · 依赖：[UI-07](UI-07-stop-runs.md)  
父级：[Spec](../../specs/2026-09-18-local-agent-ui.md) · 故事：US11、US12、US13

## 要交付什么

刷新或关闭页面再返回同会话时，恢复消息、工具记录、子任务与最新运行状态，并续接事件流。服务重启将所有未完成任务标为中断，用户手动继续生成新 Run；不重放旧工具调用。最近会话按目录恢复。

## 验收条件

- [ ] 关闭浏览器后主任务和子 Agent 继续运行；重新打开准确显示最终或当前结果。
- [ ] 刷新保留会话路由，快照和增量无缺口、无重复消息、无重复提交。
- [ ] 重启后 queued/running/stopping 及相应未完成子任务标为 interrupted，不自动启动队列。
- [ ] 点击继续创建新 Run，保留旧 Run 的终止原因、部分输出、配置版本及已完成工具结果。
- [ ] 恢复模型上下文时正确处理未配对工具调用，不能自动补跑具有副作用的工具。
- [ ] 目录失效时可读历史但禁止执行；单条历史损坏有明确处理，不让全部目录历史不可用。
- [ ] 多个浏览器标签页查看同一会话不产生重复执行，断线与任务失败明确区分。
- [ ] 正常服务退出收敛管理中的进程；异常退出/重启不宣称实现外部副作用的 exactly-once 保证。

## 验证与演示

运行中刷新、关闭浏览器、断开订阅并重连；分别正常退出和强制终止服务后重启。使用记录调用次数的工具证明页面恢复与服务重启没有自动重放副作用。
