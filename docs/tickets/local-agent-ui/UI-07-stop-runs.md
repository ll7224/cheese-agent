# UI-07 — 停止任务树与取消排队

类型：AFK · 状态：已实现，集成回归见 UI-10 · 依赖：[UI-06](UI-06-subagents.md)
父级：[Spec](../../specs/2026-09-18-local-agent-ui.md) · 故事：US10

## 要交付什么

在页面停止指定 Run：取消其排队子任务，向主任务、运行子 Agent、模型请求、重试等待和工具传播取消。后台未收敛时显示“正在停止”；完成收敛后显示“已停止”，保留已完成结果并允许继续追问。

## 验收条件

- [ ] queued 任务可取消且不会再启动；running 任务转 stopping 后禁止新工具调用与派生。
- [ ] 指定任务全部子 Agent 收到取消；同服务其他会话及其子 Agent 继续执行。
- [ ] 可管理的 shell 子进程按任务归属终止，不使用按进程名批量 kill。
- [ ] 无法立即终止的操作未结束时保持 stopping 并占用必要额度，不假报 cancelled。
- [ ] 已完成文件修改和外部副作用不自动撤销，界面说明停止不等于回滚。
- [ ] 重复停止幂等；停止/完成/超时竞争产生唯一可信终态，迟到事件不能复活任务。
- [ ] 收敛后额度准确释放、排队任务推进；新追问创建新 Run 并保留历史。

## 验证与演示

分别在流式生成、重试退避、shell 执行、子 Agent 排队/运行期间停止。用第二个会话持续输出证明停止范围正确，并验证没有残留的可管理进程。

## 实施记录

停止接口支持排队取消与运行任务 stopping；父取消传播至子任务准入、模型、重试和工具开始。Worker 先协作取消，超时后仅终止该任务进程组；退出后释放额度并收敛子任务状态。真实双 Worker 测试证明单独停止不影响另一任务；修复外部 cwd 下 tsx 加载器解析。Windows 进程树清理不属于本次 macOS 验证范围。
