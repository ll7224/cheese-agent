## 自动化与集成

执行 `npm run build`、`npm test`、`git diff --check`。17 项测试全部通过，包括 runtime、config、subagents、worker、adapters、storage、web-boundaries、tool-integration 八个文件。Mock 模型仍产生 AI SDK v2 兼容性警告，未隐藏该警告。

新增本机 OpenAI 兼容 SSE 夹具，通过真实模型适配器驱动真实 worker 和工具；不依赖外部 API、不伪造工具结果。测试覆盖跨目录文件与 shell、跨父任务的子 Agent 额度、父任务停止及排队子任务取消、Cron 工具 IPC。

Channel 使用本地 ChannelDefinition 替身；与 Web、Cron 共同提交时在单额度下得到 running/queued/queued，并按序结束，后续消息复用对应通道会话。没有发送真实飞书消息，因此飞书网络连接及实际投递保持未验证。

SSE 从游标恢复已持久化事件，浏览器关闭只取消订阅。已知配置密钥跨多个 text 分块不会进入持久化；备份恢复后首次保存不覆盖良好备份。

## 真实模型烟雾验证

使用现有配置的 Google / `gemini-3.8-flash` 兼容端点，独立临时目录、guest 角色，禁用 Channel/Cron/RAG/插件。要求 `read_file` 读取仅含 `cheese-ui10-e2e` 的 `verification.txt`，确认存在真实 tool-result，任务 completed；随后追问上一条内容，任务 completed 且包含同一标记。临时数据已删除，未记录凭据。

早期尝试曾返回 No output generated；本轮重新执行工具调用与追问成功。此结果证明当前配置当时可用，不代表所有提供商均已验证。

## 干净安装与浏览器

独立临时目录从锁文件安装 152 个包，执行 `pnpm install --frozen-lockfile --ignore-scripts`、`npm rebuild better-sqlite3`、构建及真实 worker 测试通过。第二次从该新下载缓存离线安装再次验证同一流程。编译后的独立服务使用端口 0 启动，status 返回 ready、主任务/子任务额度均为 3。

额外尝试 `npm rebuild esbuild` 失败（安装脚本将原生二进制作为 JS 执行）；已验证的文档流程不需要该命令。没有修改仓库依赖版本来掩盖安装失败。

浏览器在更新后的服务上完成键盘提交、获得实际 worker 的 mock 回复、刷新会话及执行详情展开/关闭；Escape 后焦点回到详情按钮，error 日志为空。UI-09 已检查目录接入、停止、静态视觉与窄屏抽屉。
