## 4. 运行与存储

保持 Runtime 为唯一状态来源。个人模式 `admission: 'single-reject'` 在 `startWeb` 固定启用；通用 Runtime 默认行为保留以兼容已有调用。该 Web Runtime 的 Channel/Cron 若按原配置启用，也走相同单根任务准入，忙时返回明确错误，不积累隐形队列；Cron 下一次正常计划不等于重放被拒绝的任务。独立 CLI 进程不纳入跨进程调度，此版本不提供机器级互斥。

同一根任务内部仍可派生子代理，沿用独立子任务额度；“不排队”限定新根任务。等待确认、正在停止仍占根任务位置。幂等键检查先于忙碌检查，原请求重试返回原 Run；相同键不同内容报冲突。忙碌拒绝前不追加消息、不创建 Run、不改变标题。

状态：`running → completed/failed`；`running ↔ waiting_approval`；二者可进入 `stopping → cancelled`。恢复时 legacy queued、running、waiting_approval、stopping 一律 interrupted。已有 queued 历史可显示，不再产生面向用户的根任务队列。只有任务树真正结束才释放位置。多项审批并行出现时，待确认计数大于零就显示 waiting_approval；其他已发出的只读工作可能仍完成，UI 不把等待确认描述为整棵树已暂停。

Session 增加可选 `archivedAt`，缺省代表未归档。重命名不改变目录；标题 trim 后 1–100 字符。归档需无活跃 Run，可取消归档；归档会话不可直接提交。标题搜索在分页前执行，按更新时间倒序，范围为选定工作目录。无自动跨会话记忆写入；明确调用现有记忆工具时仍受权限策略控制。

保留现有原子 JSON + 备份存储，不同时迁移数据库。增加 `schemaVersion: 2` 和可选 approvals；加载旧快照补缺省值，首次写前保留备份，拒绝未来未知版本。持久化失败沿用停止准入并取消运行的处理。审批的私有原始参数只保留在服务内存；持久化脱敏摘要与摘要哈希，重启后不能据此自动执行。

自动目录位于 `<dataDir>/workspaces/<UUID>`，仅创建此服务管理的目录，权限 0700；用户不能通过名字指定父目录。失败清理仅限本次创建且为空的目录。归档不删目录。

## 5. 权限与审批

审批不是沙箱，cwd 不是权限边界。授权必须在副作用之前，且 Pre Hook 改写后的最终参数再次检查。主代理/子代理、普通/无锁包装、插件工具均经过同一个授权入口；权限基础设施异常时拒绝执行。RBAC 和硬性禁令优先，批准不自动提升角色。

内置路径工具以规范化工作目录为默认范围；已有路径使用 realpath，新增文件验证最近已存在父目录、后续路径段和符号链接。预览 API 永不读取根目录外路径。工具越界请求进入审批并绑定目标路径；默认不授予整个目录树。实现必须测试符号链接替换竞争，不能把一次 realpath 检查当完整保证。

Shell 采用单独受限执行器：工作区和每次任务独立临时目录可写，配置、会话数据及工作区外默认不可写。运行时只读资源需明确允许。平台适配先以当前 macOS 做实际子进程探针验证；验证重定向、Node/Python 子进程、符号链接和派生子进程都不能绕过。未验证或不支持的后端不能静默降级为 unrestricted exec。实现前探针决定使用系统沙箱还是维护中的隔离依赖，并在实施记录中写明机制及限制；不能仅以正则分类完成 R09。

只有经过验证的受限执行和明确允许的测试命令可直接执行。删除/提权/越界写入请求展示准确命令、目录、目标与理由；授权仅对该次操作生效。可安全表达的越界许可扩展到明确目标；无法表达的操作拒绝并说明原因。破坏性硬禁令依然拒绝。MCP/插件未知副作用默认要求确认，不自动把工具名称视为只读。第一版不承诺远程服务的 OS 沙箱隔离。

Approval：id、runId、toolCallId、可选 childRunId、脱敏操作摘要、最终参数哈希、状态 pending/approved/denied/expired。批准请求只带 id 与 decision，不能带替换后的命令。服务核对当前任务、原始参数哈希及未处理状态；批准消费一次；重复同决策返回原结果，反向改判返回 409。拒绝作为工具被拒绝结果回给 Agent；停止或退出使 pending 失效，拒绝等待 Promise。批准和停止竞争时执行前再次检查 signal。

若某个工具动作开始后未收到结果，恢复时生成 `tool-unknown` 展示事件，以 toolCallId 匹配，不伪造成功或失败。后续 Run 获得结构化未完成操作提示，先检查现场。模型重试只允许确定尚未产生工具副作用的尝试；无法确定则失败，由用户继续。

## 6. 文件与前端

React + Vite 放在 `web/`，构建产物 `web/dist/`，Hono 同源提供。保留现有 hash 会话 URL、草稿 key、事件 ID 去重和连接状态语义。开发时 Vite 代理 API；生产不依赖 Vite 服务。保留旧页面直至对等行为验证后再删除旧入口，避免双套生产入口。

文件列表单层分页，默认 100、最大 200 项；`.git`、`node_modules` 默认隐藏。路径始终相对 workspace，越界/符号链接越界返回 403；特殊设备、FIFO、socket 拒绝。文本预览上限 1 MiB，二进制只显示元信息/下载；超过限制明确提示不截断伪装完整文件。Markdown 禁用原始 HTML，清理 URL 协议，不自动加载远程图片；本地资源仅经受约束的文件 API。代码/文本以纯文本渲染。

下载流式处理，Content-Disposition 为 attachment，nosniff，不把 HTML/SVG 作为同源可执行页面。复制绝对路径由 API 返回规范化路径。文件工具成功写入后发 `file-changed`；Shell 修改通过刷新目录看到，不称为完整变更审计。子代理审批/变更带 childRunId。

命令启动成功监听后才打开默认浏览器；打开失败仍打印 URL，服务继续；增加 `--no-open` 便于测试和无图形环境。不在错误路径重复打开浏览器。

## 7. API 增量

| 方法与路径 | 契约 |
| --- | --- |
| PATCH /api/v1/sessions/:id | `{title?, archived?}`，返回 Session 概况；活跃时归档 409 |
| GET /api/v1/sessions | 增加 q、archived（默认 false），保留 workspaceId/offset/limit |
| POST /api/v1/workspaces/managed | 创建服务管理的独立目录，返回 Workspace |
| GET /api/v1/workspaces/:id/files | relative path、offset、limit；返回 entries、total |
| GET /api/v1/workspaces/:id/file | relative path；返回文本/元信息，预览超限 413 |
| GET /api/v1/workspaces/:id/download | relative path；返回受控附件流 |
| POST /api/v1/approvals/:id/decision | `{decision: 'approve'|'deny'}`；过期/冲突 409 |

Session 快照包含该会话待确认摘要，SSE 增加 approval、file-changed、tool-unknown 事件。既有 Host/Origin/JSON/请求大小限制覆盖新接口。批准接口校验浏览器同源请求；本机服务并非抵御同权限恶意本地进程的安全边界。

## 8. 验收与实施顺序

1. 旧数据兼容与单根任务准入，包括等待确认/停止占位与其他入口忙碌行为。
2. 会话管理与自动目录；不丢历史、不改用户工作目录。
3. 统一授权入口、平台执行边界探针；未通过不能进入“普通测试自动执行”交付。
4. 审批 IPC 与恢复/取消/副作用未知语义。
5. 受约束文件 API 与变更事件。
6. React 页面迁移及会话/时间线/审批/文件交互。
7. 编码与文档完整闭环、真实 worker 权限/取消探针、浏览器恢复验证。

使用 node:test、临时目录和本地可控模型，不要求付费模型或真实外部消息。真实模型烟雾验证另记证据。最终必须通过：Markdown 报告生成和预览；代码修改和测试；刷新不重复执行；停止后修改保留；服务退出后中断；审批不重复/过期不可执行；Shell/子代理越界不能静默成功。
